# 分类与问题维护说明（给使用同事）

**所有设置都在同一个页面**：打开应用 → 点上方「**问题与选项**」标签。

改完点「**保存**」，**立即生效，不需要重启任何东西**。

> 应用地址：**http://127.0.0.1:8100** （建议存书签）
> 直接进设置页：http://127.0.0.1:8100/#questions

---

## 一、界面语言

右上角可以切换**界面语言**：中文 / English / Bahasa Melayu。

切了之后，**所有界面文字和结果都跟着变**（分类名、选项文字、档位文字、按钮、提示），
跟输入内容是什么语言无关。

链接也可以直接指定语言，方便分享：
- http://127.0.0.1:8100/?lang=zh
- http://127.0.0.1:8100/?lang=en
- http://127.0.0.1:8100/?lang=ms

---

## 二、页面长什么样

设置页从上到下是**一串问题**，编号 Q1、Q2、Q3…：

| | 是什么 | 能不能改 |
|---|---|---|
| **Q1 分类问题** | 判定内容属于哪一类。它的**「选项 Choices」就是分类本身** | 措辞可改；不能停用或删除 |
| **Q2 起** | 附加问题（紧急程度、负面情绪、需人工介入、有害内容…） | 全都能改、能停用、能删除、能新增 |

> **原来的「分类管理」标签已经并入这里**——因为分类就是 Q1 这个多选一问题的选项，
> 分开放两个页面反而不好理解。现在改分类 = 改 Q1 的选项。

页面顶部有一排按钮：

| 按钮 | 作用 |
|---|---|
| **＋ 添加问题** | 在最后新增一个附加问题（Q2 起） |
| **保存** | 保存全部改动并立即生效 |
| **放弃修改** | 撤销未保存的改动，回到服务器当前生效的版本 |
| **提问预览** | **展开/收起**：看模型实际收到的每一条提问（强烈建议改完看一眼） |
| **导出完整设置** | 把分类 + 问题存成一个 JSON 文件，用于备份或搬到别的电脑 |
| **导入表格** / **导出 Excel** / **导出 CSV** | 只针对**分类**的表格导入导出（不含问题） |

## 三、Q1 的选项（= 分类）怎么改

在 Q1 卡片里找到「**选项 Choices**」，每一行就是一个分类，左边有 A、B、C… 的字母编号。

**每一行有：**

| 字段 | 填什么 |
|---|---|
| **标识** | 英文代号，只能用英文字母开头，后面跟英文字母、数字或下划线。例如 `delivery` |
| **启用** | 勾上才参与判定；不勾就暂时不用（比删掉安全，随时能勾回来） |
| **名称** | 界面上显示的名字，越短越好。例如 `配送问题` |
| **描述** | **给模型看的说明，这一栏最重要**。例如 `配送太慢、送错地址或配送员问题` |

**加一个分类**：点「＋ 添加选项」，填完保存。
**停用一个**：去掉「启用」勾选（不用删行）。
**删除**：点右边「删除」。

右上角有数量提示，例如 `已启用 6 / 建议不超过 12`。

### `other` 那一行是锁定的

它显示一个 **🔒 固定不可改** 标记，**没有删除按钮**、启用勾选框是灰的、标识是只读的。
名称和描述**仍然可以改**。

**为什么锁死它**：它负责承接「不属于任何分类」的内容。没有它，域外内容会被**硬塞进某个分类里**，
而且看起来还很"确定"——这是最难发现的失效模式，因为页面上完全看不出异常。

> 即使有人绕过网页（直接改配置文件、或用脚本调接口）把它删掉，
> 服务端也会**自动补回来并重新启用**，同时给你一条提示。所以这一项破坏不了。

## 四、Q2 起的附加问题怎么改

每个问题卡片可以改：

| 字段 | 说明 |
|---|---|
| **启用** | 不勾就不问这个问题了 |
| **标识** | 英文代号。**不能叫 `category`，也不能用 `is_` 开头**（内部保留） |
| **类型** | `choice` 多选一 / `score` 打分 / `noul` 是/否（见下） |
| **显示名称** | 结果卡片上显示的标题 |
| **提问** | **真正送给模型的句子**。改它才是真正改了问题 |
| **选项 / 档位** | `choice` 填选项（至少 2 个）；`score` 填档位（至少 2 档）；`noul` 不用填 |

### 三种类型怎么选

| 类型 | 结果长什么样 | 适合问什么 |
|---|---|---|
| `choice` | 选中的选项 + 各选项概率 | 归类、分流（「该由哪个部门处理」） |
| `score` | 一个档位期望值（如 2.31 / 3） | 程度类（紧急度、愤怒度、严重度） |
| `noul` | 一个 0–100% 的概率 | 是非题（「是否要求退款」） |

点「**提问预览**」可以看到三种类型的完整说明，以及模型实际收到的每一条提问。

### `noul`（是非题）为什么不让填选项

实测：给是非题**加上选项文字反而会判错**。所以界面上这一栏是空的、也不让你填。

## 五、三种语言的填写规则（重要）

每个分类、每个问题都有**中文 / English / Bahasa Melayu** 三套文字。页面顶部有语言按钮，切换着填。

**判定时用的是哪一套，是有规定的：**

| 输入内容的语言 | 给模型看的是 |
|---|---|
| 中文 | **中文**描述 / 提问 |
| 马来文、其他 | **英文**描述 / 提问 |

为什么马来文用英文？实测过：同样的马来文内容，配英文问题准确率 **3/4**，配马来文问题只有 **2/4**。

**实际建议**：至少把「中文」和「英文」两套都填上。马来文只填名称也行（界面显示用）。

某栏空着时，系统按 中文 → 英文 → 马来文 的顺序找一个非空的来用，不会直接报错。

## 六、保存后怎么确认生效了

页面顶部会显示状态：

- `✓ 分类配置已生效：N 个分类` —— 成功了
- `✗ 分类配置有错误，正在沿用上一份可用配置` —— 没生效，下面会逐条写清楚哪里有问题。
  **此时系统会自动沿用你上次保存成功的那份配置**，不会崩，你有时间慢慢改。

**校验不通过时，什么都不会被保存**，不用担心"改坏一半"。

**改完问题，建议点「提问预览」看一眼**——那里显示的是真正送给模型的每一条提问，
能确认你的改动确实生效了、而且措辞符合预期。

## 七、两条硬规则

### 1. `other` 不能删（见第三节）

### 2. 改「描述」或「提问」的文字会让结果变化，改完必须重新测试

这条很重要，是我们实测出来的：

> 同一段内容，**只把某句文字的措辞换个说法**，判定结果就会变。
> 例如把 `程序错误、服务中断或集成问题` 改成 `故障报修，程序报错或服务中断`，
> 同一段退款投诉就从「退款」变成了「故障报修」——而两次给出的"可能性百分比"几乎一样（97.5% vs 97.7%）。

所以：

- **不要凭感觉润色文字**，觉得"这样说更顺"就改
- 想改，**先用 10～20 条真实内容测一遍**，对比改之前和改之后
- 界面上那个百分比**不代表准确率**，不要以它为判断依据
- 判断结果可不可信，看的是 **「两种问法一致 / 不一致」** 那个标记——不一致时尤其不要采信

---

## 八、选项数量不要太多

分类建议控制在 **12 个以内**（页面会提示）。选项越多，每个选项分到的"注意力"越少，准确率会下降。

分类特别多时，更好的做法是**两级**：先用 5～6 个大类分一次，再在选中的大类里细分。

附加问题同理，建议不超过 12 个。

## 九、导入 / 导出

| 按钮 | 内容 | 用途 |
|---|---|---|
| **导出完整设置** | 分类 + 问题，JSON | **首选备份方式**。换电脑、改乱了想恢复，用这个 |
| **导出 Excel** | 只有分类，`.xlsx` | **用 Excel 直接改**。表头加粗、列宽已调好、首行冻结，打开就能填 |
| **导出 CSV** | 只有分类，`.csv` | 同上，给不方便用 Excel 的场合 |
| **导入表格** | 只有分类 | 支持 **`.xlsx` / `.xlsm` / `.csv` / `.tsv`**。**格式自动识别**，不用你说明是哪种。导入后**不会立刻生效**，会先显示在页面上让你检查，确认再点保存 |

**列顺序**（导入导出都一样）：
`启用, 标识, 中文名称, 中文描述, 英文名称, 英文描述, 马来文名称, 马来文描述`

- 表头必须原样保留这几列；**多出来的列会被忽略**（你可以拿它当备注栏用）
- 「启用」列接受 `1/0`、`是/否`、`y/n`……Excel 里填成数字 1 也行
- 兼容旧版只有 6 列（没有马来文那两列）的表格

**关于 Excel 格式**：导出的 `.xlsx` 是真正的 Excel 文件（不是改了后缀的 CSV），
可以用 Excel / WPS / Numbers 正常打开编辑。反过来，**员工用 Excel 另存出来的文件
（包括"文本(制表符分隔)"）也能直接导入**——格式按文件内容自动判断，不需要你声明。

> 服务器需要 `openpyxl` 才能处理 Excel。如果没装，Excel 按钮会给出明确提示，
> 重新运行 `install.bat` 或执行 `pip install openpyxl` 即可。CSV / TSV 不受影响。
（兼容旧版只有 6 列的表格。）

同目录下的 `示例-电商客服.csv`、`示例-人力资源.csv` 是整套分类模板，可以直接导入看效果。

## 十、这个系统的能力边界（请务必知道）

它**不是自动判定系统**，只是一个给你"看一眼"的参考工具。原因：

- 模型对措辞极度敏感（见第七节）
- 给出的"可能性百分比"**与正确性无关**，对错两种情况数字差不多
- 两种问法有时会**一致地给出错误答案**

实测准确率参考（专门构造的测试集）：英文 10/13、中文 12/17、马来文 8/13。中文和马来文都明显偏弱。

**所以：任何对外发出的处理动作，都必须由人确认后再做。不要把它接到自动流程里。**
